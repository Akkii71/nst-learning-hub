# NST Learning Hub

A syllabus-specific, community-powered learning platform for NST students.

## Project Structure

```
nst-learning-hub/
  mobile/     - React Native (Expo) mobile application
  server/     - Node.js + Express REST API backend
```

## Running the Mobile App

```bash
cd mobile
npm install
npm start
```

Then scan the QR code with the Expo Go app on your phone.

## Running the Server

```bash
cd server
npm install
npm start
```
